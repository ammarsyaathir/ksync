1. Database Architecture & Design Rationale

Section 1.0

The K-Sync Malaysia database is modeled specifically to solve the 3 core problems identified in Chapter 1: Introduction: (1) Fragmented event information, (2) Unverified submissions and scalper fraud, and (3) Disorganized community event coordination.

Design Optimization: The schema was intentionally streamlined from 23 tables down to 10 purposeful tables. Unnecessary overhead (such as separate venue lookup tables, GPS check-ins, and 1-on-1 private messaging) was eliminated, focusing 100% of system resources on centralized discovery, community discussion, and administrator verification.

Key Structural Architectural Decisions:

  • Embedded Venue Attributes in Events: Rather than maintaining a detached venues lookup table that requires complex relational joins, venue attributes (venue_name, address, city, state) are natively embedded into the events record. This enables seamless support for both mega arenas (Axiata Arena, Zepp KL) and custom fan cupsleeve cafes.
  • Single-Table Idol Member Biodata: Group and soloist member biodata (stage name, birth name, positions, birthday, zodiac, height, blood type, and MBTI) is stored in the artists.members column formatted as structured JSON. This satisfies user requirements without introducing a redundant artist_members child table.
  • Dual Engine Compatibility: The data dictionary supports both Hostinger Cloud MySQL 8.0 in production (via mysql2/promise) and SQLite 3 in local development, ensuring zero deployment friction.

3. Cardinality & Multiplicity Relationship Matrix

Section 3.0

This table defines the participation constraints, multiplicities, foreign key mapping, and referential integrity delete actions across all relationships.

# Parent Entity Child Entity Foreign Key Column Cardinality Business Relationship Rule ON DELETE
1 roles users users.role_id 1 : N One role is assigned to zero or many users. A user must have exactly 1 role. RESTRICT
2 event_categories events events.category_id 1 : N One category classifies zero or many events. An event belongs to exactly 1 category. RESTRICT
3 artists events events.artist_id 1 : N One artist performs in zero or many events. An event features zero or one artist. SET NULL
4 users events events.organizer_id 1 : N One organizer manages zero or many events. An event has 1 organizer account. RESTRICT
5 users & events saved_events user_id, event_id M : N Many-to-Many resolved by associative table. Fans bookmark multiple events. CASCADE
6 events event_chat_messages event_id 1 : N One event hub contains zero or many community chat messages. CASCADE
7 users event_chat_messages user_id 1 : N One registered fan authors zero or many chat messages. CASCADE
8 events reports reports.event_id 1 : N One event listing can have zero or many content/scam reports. CASCADE
9 users reports reports.user_id 1 : N One user submits zero or many reports (optional if guest reports). SET NULL
10 users activity_logs activity_logs.user_id 1 : N One administrator/user triggers zero or many immutable audit records. SET NULL
11 users notifications notifications.user_id 1 : N One user receives zero or many in-app alerts and soundcheck updates. CASCADE

4. Complete Data Dictionary (10 Tables)

Section 4.0
4.1 Table: roles RBAC Roles Table
Stores user role designations for role-based access control.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Surrogate primary key for role.
name VARCHAR(50) NO UK NULL Unique role title: Admin, Organizer, Fan.
created_at DATETIME YES - CURRENT_TIMESTAMP Timestamp when the role record was initialized.
4.2 Table: users User Accounts & Profiles
Stores registered user credentials, profiles, and organizer verification metadata.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique user identifier.
role_id INT NO FK 3 References roles(id). Default 3 = Fan.
full_name VARCHAR(100) NO - NULL User's full display or legal name.
username VARCHAR(50) NO UK NULL Unique login username / handle.
email VARCHAR(100) NO UK NULL Unique email address used for sign-in and notifications.
password_hash VARCHAR(255) NO - NULL Bcrypt-hashed password string.
bio TEXT YES - NULL Short user biography or fanclub description.
profile_image VARCHAR(255) YES - NULL URL or uploaded path to avatar photo.
organization_name VARCHAR(150) YES - NULL Official registered organizer or fanclub organization name.
organization_type VARCHAR(50) YES - 'Fanclub' Entity type: Fanclub, Promoter, Agency.
social_handle VARCHAR(50) YES - NULL Official X / Instagram username (e.g. @TXT_MY).
social_url VARCHAR(255) YES - NULL Direct URL to official organizer announcement channel.
location VARCHAR(100) YES - 'Kuala Lumpur' Malaysian city/state of the user.
status VARCHAR(20) YES - 'ACTIVE' Account status: ACTIVE, SUSPENDED.
created_at DATETIME YES - CURRENT_TIMESTAMP User account registration timestamp.
updated_at DATETIME YES - CURRENT_TIMESTAMP Timestamp of latest profile modification.
4.3 Table: artists K-Pop Artists & Idol Biodata
Stores idol groups and soloists, embedding all member profiles directly inside JSON format.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique artist catalog identifier.
name VARCHAR(100) NO - NULL Official artist/group name (e.g. TOMORROW X TOGETHER).
group_type VARCHAR(50) YES - 'Boy Group' Category: Boy Group, Girl Group, Soloist.
image_url VARCHAR(255) YES - NULL Header / promotional group photo asset URL.
agency VARCHAR(100) YES - NULL Management entertainment agency (e.g. BIGHIT MUSIC).
description TEXT YES - NULL Career summary and background biography of the artist.
members LONGTEXT (JSON) YES - NULL JSON array holding individual idol biodatas (Stage name, birth name, positions, DOB, zodiac, height, blood, MBTI).
created_at DATETIME YES - CURRENT_TIMESTAMP Timestamp when artist was added to catalog.
4.4 Table: event_categories Event Type Taxonomy
Categorization taxonomy for Malaysian K-Pop events.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique category identifier.
name VARCHAR(100) NO UK NULL Category title (e.g. Concert, Fan Meeting, Cupsleeve Event).
slug VARCHAR(100) NO UK NULL URL slug for filtering (e.g. fan-meeting).
badge_color VARCHAR(30) YES - 'purple' Tailwind color theme for UI badges (purple, pink, rose).
description TEXT YES - NULL Scope and definition of the event category.
created_at DATETIME YES - CURRENT_TIMESTAMP Timestamp when category was established.
4.5 Table: events Centralized Event Information (Embedded Venue)
Central repository of verified K-Pop events, ticketing tiers, rules, embedded venue details, and public submission tracking codes.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique event identifier.
organizer_id INT NO FK 2 References users(id) (Managing organizer/promoter).
artist_id INT YES FK NULL References artists(id). Set null if multiple artists.
category_id INT NO FK NULL References event_categories(id).
event_name VARCHAR(200) NO - NULL Full official title of the Malaysian event.
description TEXT YES - NULL Itinerary, setlist highlights, soundcheck perks, and overview.
event_date DATE NO - NULL Calendar date of performance (YYYY-MM-DD).
start_time TIME NO - NULL Doors open / concert start time (HH:MM:SS).
end_time TIME YES - NULL Estimated conclusion time (used for 24h chat auto-lock).
venue_name VARCHAR(150) NO - NULL Embedded Venue Name (e.g. Zepp Kuala Lumpur).
address TEXT YES - NULL Embedded Street Address (e.g. LaLaport BBCC, Jalan Hang Tuah).
city VARCHAR(100) NO - NULL Embedded City (e.g. Kuala Lumpur).
state VARCHAR(100) NO - NULL Embedded State (e.g. Wilayah Persekutuan Kuala Lumpur).
ticket_info TEXT YES - NULL Ticket tiers, seated categories, and pricing breakdown.
event_rules TEXT YES - NULL Prohibited items (cameras, large bags), soundcheck queue rules.
official_url VARCHAR(255) YES - NULL Official verified ticketing link (BookMyShow, GoLive, Ticket2U).
poster_image VARCHAR(255) YES - NULL Promotional poster image URL or uploaded file location.
event_status VARCHAR(30) YES - 'UPCOMING' Life cycle: UPCOMING, ONGOING, COMPLETED.
verification_status VARCHAR(30) YES - 'PENDING' Review state: PENDING, VERIFIED, REJECTED.
rejection_reason TEXT YES - NULL Administrator recorded reason explaining submission rejection.
tracking_code VARCHAR(50) YES UK NULL Unique tracking code (e.g. KS-2026-TXT001) for public status lookup.
submitter_name VARCHAR(150) YES - NULL Name of the public submitter or fanclub organizer.
submitter_email VARCHAR(150) YES - NULL Contact email where review notifications are delivered.
created_at DATETIME YES - CURRENT_TIMESTAMP Submission timestamp.
updated_at DATETIME YES - CURRENT_TIMESTAMP Last modification timestamp.
4.6 Table: saved_events Fan Bookmarks Associative Table
Resolves the M:N relationship between users and bookmarked events with personal countdown timers.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Surrogate primary key.
user_id INT NO FK NULL References users(id). Deleted on user cascade.
event_id INT NO FK NULL References events(id). Deleted on event cascade.
saved_at DATETIME YES - CURRENT_TIMESTAMP Timestamp when bookmark was saved.
4.7 Table: event_chat_messages Live Event Discussion Hub
Stores per-event discussion messages exchanged between registered fans with automatic 24-hour post-event archival.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique chat message identifier.
event_id INT NO FK NULL References events(id) to isolate discussions by show.
user_id INT NO FK NULL References users(id) of message author.
message TEXT NO - NULL Sanitized message body text.
created_at DATETIME YES - CURRENT_TIMESTAMP Message creation timestamp.
4.8 Table: reports Community Content Flagging
Records community reports flagging fraudulent listings, inaccurate event times, or inappropriate content.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique report tracking identifier.
user_id INT YES FK NULL References users(id) (Reporter). Set NULL if anonymous guest.
event_id INT YES FK NULL References events(id) being flagged.
report_type VARCHAR(50) YES - 'EVENT' Classification: EVENT, CHAT, SCAM.
reason VARCHAR(255) NO - NULL Category: Inaccurate Date, Fake Event, Scalper Resale Link.
details TEXT YES - NULL Supporting evidence or official link provided by reporter.
status VARCHAR(30) YES - 'PENDING' Resolution state: PENDING, INVESTIGATING, RESOLVED.
created_at DATETIME YES - CURRENT_TIMESTAMP Filing timestamp.
4.9 Table: activity_logs Administrator Audit Trail
Maintains an immutable historical record of all administrative verifications, approvals, and moderation actions.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique log identifier.
user_id INT YES FK NULL References users(id) of the administrator who executed action.
action VARCHAR(50) NO - NULL Action code: APPROVE_EVENT, REJECT_EVENT, DELETE_USER.
target_type VARCHAR(50) YES - NULL Target entity: events, users, categories, artists.
target_id INT YES - NULL Primary key of modified target record.
details TEXT YES - NULL Human-readable summary of the administrative action.
ip_address VARCHAR(50) YES - NULL Client IPv4/IPv6 address of executor for security auditing.
created_at DATETIME YES - CURRENT_TIMESTAMP Action execution timestamp.
4.10 Table: notifications User & Organizer Alerts
Stores user notifications for soundcheck queues, ticket sales, and event submission outcomes.
Column Name Data Type Null Key Default Description
id INT NO PK AUTO_INCREMENT Unique notification identifier.
user_id INT NO FK NULL References users(id) of recipient.
title VARCHAR(150) NO - NULL Notification headline banner.
message TEXT NO - NULL Detailed alert notification message.
link VARCHAR(255) YES - NULL Target route URL (e.g. /events/1).
is_read TINYINT(1) YES - 0 Read flag: 0 = Unread, 1 = Read.
created_at DATETIME YES - CURRENT_TIMESTAMP Alert dispatch timestamp.
